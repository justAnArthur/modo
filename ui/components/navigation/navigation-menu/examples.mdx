# Indicator

A `NavigationMenu.Indicator` in the list takes over the marker under the open
item (else the current page's link), so `className` can fill it.

# Router links

A router's link component goes in `render` and `active` follows the route; the link keeps its classes, hover and keys.

```tsx
<NavigationMenu.Link render={<RouterLink to="/pricing" />} active={pathname === '/pricing'}>
  Pricing
</NavigationMenu.Link>
```
