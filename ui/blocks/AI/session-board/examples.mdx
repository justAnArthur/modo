import SessionBoard from './index'

# By project

The sidebar's groups and order, widened: each row names its profile and project, what it waits on or where its tasks stand, and its last activity. The canvas session waits on a permission: allow or deny it from the row, or answer it in its open card. Open the Meter session too: each open row is its own card.

<div className="w-full">
  <SessionBoard defaultOpen={['canvas', 'meter']} />
</div>

# By state

The same rows by what each session needs from you. The Postgres question opens with its options, answerable in place.

<div className="w-full">
  <SessionBoard defaultView="state" defaultOpen={['pg']} />
</div>

# Filtered

`defaultFilter="profile:work"` shows only the work profile's sessions; "Show all" clears it.

<div className="w-full">
  <SessionBoard defaultFilter="profile:work" />
</div>

# Narrow

Below the wide breakpoints the project and status columns fold away and Allow / Deny shrink to icons.

<div className="w-full max-w-[420px]">
  <SessionBoard defaultOpen={['canvas']} />
</div>
