# Labelled

With no text beside it, give it a `label` for screen readers.

<div className="flex items-center gap-3">
  <StatusDot status="running" label="Running" />
  <StatusDot status="waiting" label="Needs your input" />
  <StatusDot status="error" label="Failed" />
</div>

# Sizes

It sits on the size ladder's icon step: 16px, or 14px compact.

</div>
