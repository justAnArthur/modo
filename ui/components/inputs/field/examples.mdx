# Field

A label above the control, help text below it. Press the label: it focuses the input, and the description is read with it.

<Field className="w-72 max-w-full">
  <Field.Label>Email</Field.Label>
  <Input icon={Mail} placeholder="you@example.com" />
  <Field.Description>We only write about your account.</Field.Description>
</Field>

# Any field control

Textarea, Select, Combobox and the pickers join the same way: the label names them, and the field's state reaches them.

<div className="flex w-72 max-w-full flex-col gap-4">
  <Field>
    <Field.Label>Message</Field.Label>
    <Textarea placeholder="Write your message" minRows={2} />
  </Field>
  <Field>
    <Field.Label>Fruit</Field.Label>
    <Select defaultValue="banana">
      <Select.Trigger />
      <Select.Content>
        <Select.Item value="apple">Apple</Select.Item>
        <Select.Item value="banana">Banana</Select.Item>
        <Select.Item value="cherry">Cherry</Select.Item>
      </Select.Content>
    </Select>
  </Field>
  <Field>
    <Field.Label>Framework</Field.Label>
    <Combobox items={[{ value: 'next', label: 'Next.js' }, { value: 'astro', label: 'Astro' }, { value: 'remix', label: 'Remix' }]}>
      <Combobox.Input placeholder="Select a framework…" />
      <Combobox.Content>
        <Combobox.Empty>No framework found.</Combobox.Empty>
        <Combobox.List>
          {(item) => (
            <Combobox.Item key={item.value} value={item.value}>
              {item.label}
            </Combobox.Item>
          )}
        </Combobox.List>
      </Combobox.Content>
    </Combobox>
  </Field>
  <Field>
    <Field.Label>Due date</Field.Label>
    <DatePicker placeholder="Pick a date" />
  </Field>
</div>

# Field.Control

An element that isn't one of the field controls takes the field's id, `aria-describedby` and `aria-invalid` through `Field.Control`, here a native select.

<Field className="w-72 max-w-full">
  <Field.Label>Country</Field.Label>
  <Field.Control
    render={
      <select className="h-9 w-full bg-transparent px-1.5 text-body text-foreground">
        <option>Slovakia</option>
        <option>Czechia</option>
        <option>Austria</option>
      </select>
    }
  />
  <Field.Description>Where the invoice is sent.</Field.Description>
</Field>

# Hidden label

`visuallyHidden` keeps the label for assistive tech where the placeholder carries the meaning.

<Field className="w-72 max-w-full">
  <Field.Label visuallyHidden>Search</Field.Label>
  <Input variant="bordered" placeholder="Search people" />
</Field>

# Compact

`size` pins the field and its control to the compact step.

<Field size="compact" className="w-64 max-w-full">
  <Field.Label>Filter</Field.Label>
  <Input placeholder="Name contains…" />
  <Field.Description>Matches any part of the name.</Field.Description>
</Field>

# Error

`invalid` turns the label and the box destructive, and `Field.Error` shows its message while it has one. Both come from your validation. Select, Combobox and the pickers turn destructive the same way.

<div className="flex w-72 max-w-full flex-col gap-4">
  <Field invalid>
    <Field.Label>Email</Field.Label>
    <Input icon={Mail} defaultValue="ada@" />
    <Field.Error>Enter a full address, like ada@example.com.</Field.Error>
  </Field>
  <Field invalid>
    <Field.Label>Start date</Field.Label>
    <DatePicker placeholder="Pick a date" />
    <Field.Error>Pick a start date.</Field.Error>
  </Field>
</div>

# Required and native validation

`required` marks the label with an asterisk and the control `required`. With `validationMode`, Base UI checks the control's own rules and the field turns destructive on a failure; an empty `Field.Error` shows the browser's message. Type something that isn't an address and leave the field.

<Field required validationMode="onBlur" className="w-72 max-w-full">
  <Field.Label>Work email</Field.Label>
  <Input type="email" icon={Mail} placeholder="you@company.com" />
  <Field.Error />
</Field>

# Disabled and read-only

The field hands its state to the control: `disabled` dims everything, `readOnly` keeps the value selectable and a popup shut. A control's own prop still wins: the last select sets `readOnly={false}`.

<div className="flex w-72 max-w-full flex-col gap-4">
  <Field disabled>
    <Field.Label>Workspace</Field.Label>
    <Input defaultValue="Design" />
    <Field.Description>Only owners can rename it.</Field.Description>
  </Field>
  <Field readOnly>
    <Field.Label>Invoice number</Field.Label>
    <Input defaultValue="INV-2026-0042" />
  </Field>
  <Field readOnly>
    <Field.Label>Plan</Field.Label>
    <Select defaultValue="pro">
      <Select.Trigger />
      <Select.Content>
        <Select.Item value="free">Free</Select.Item>
        <Select.Item value="pro">Pro</Select.Item>
      </Select.Content>
    </Select>
  </Field>
  <Field readOnly>
    <Field.Label>Seat type</Field.Label>
    <Select defaultValue="editor" readOnly={false}>
      <Select.Trigger />
      <Select.Content>
        <Select.Item value="viewer">Viewer</Select.Item>
        <Select.Item value="editor">Editor</Select.Item>
      </Select.Content>
    </Select>
  </Field>
</div>
