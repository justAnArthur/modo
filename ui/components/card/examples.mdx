# Basic

Borderless inline list: icon + a ghost action, divided by hairlines.

<div className="w-full max-w-[520px]">
  <Card.Group orientation="inline">
    {[
      { icon: Circle, title: 'Fluid motion', description: 'Spring-tuned transitions calibrated across three tiers' },
      { icon: Shield, title: 'Accessible by default', description: 'Focus-visible rings and ARIA roles in every part' },

      { icon: Moon, title: 'Dark mode ready', description: 'Tokens adapt to light and dark automatically' },
    ].map((f) => (
      <Card key={f.title} onClick={() => {}}>
        <Card.Media icon={f.icon} />
        <Card.Header>
          <Card.Title>{f.title}</Card.Title>
          <Card.Description>{f.description}</Card.Description>
        </Card.Header>
        <Card.Footer>
          <Card.Button>Connect</Card.Button>
        </Card.Footer>
      </Card>
    ))}
  </Card.Group>
</div>

# Selected

Click a card to select it: the selected card carries the fill, its title
bolds, and the group drops the dividers around it. Each card has a `value`;
the group holds the selection (`defaultValue` here, or `value` and
`onValueChange` to control it). `selected` on a card overrides the group.

<div className="w-full max-w-[520px]">
  <Card.Group orientation="inline" defaultValue="Accessible by default">
    {[
      { icon: Circle, title: 'Fluid motion', description: 'Spring-tuned transitions calibrated across three tiers' },
      { icon: Shield, title: 'Accessible by default', description: 'Focus-visible rings and ARIA roles in every part' },
      { icon: Palette, title: 'Yours to theme', description: 'Swap radius, icons, and primitive at runtime' },
      { icon: Moon, title: 'Dark mode ready', description: 'Tokens adapt to light and dark automatically' },
    ].map((f) => (
      <Card key={f.title} label={f.title} value={f.title}>
        <Card.Media icon={f.icon} />
        <Card.Header>
          <Card.Title>{f.title}</Card.Title>
          <Card.Description>{f.description}</Card.Description>
        </Card.Header>
      </Card>
    ))}
  </Card.Group>
</div>

# Outlined card and dividers

`border="outlined"` frames a standalone card in the hairline an outlined
group gives its tiles. `Card.Divider` runs a hairline across the card
between its parts, full-bleed and spaced like them; in an inline card it
stands vertical.

<div className="flex w-full max-w-[520px] flex-col gap-4">
  <Card border="outlined">
    <Card.Header>
      <Card.Title>Team plan</Card.Title>
      <Card.Description>Everything in Pro, for up to ten seats.</Card.Description>
    </Card.Header>
    <Card.Divider />
    <Card.Content>
