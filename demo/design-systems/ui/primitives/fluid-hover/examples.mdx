# Blink or glide

Plain `:hover` blinks off in every gap; this one glides, melting from row to
row. Run the cursor down the rows, into the padding and past the last row.

<div className="w-64 rounded-xl border border-border/60">
  <FluidHover className="p-2" items={['Inbox', 'Drafts', 'Sent', 'Archive', 'Trash']} />
</div>
