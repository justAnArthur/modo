# Ten thousand rows

Only the rows in view are mounted; scroll as fast as you like.

<VirtualList
  label="Events"
  count={10000}
  itemHeight={36}
  className="h-72 w-full max-w-md rounded-xl border border-border"
  renderItem={i => (
    <div className="flex h-full items-center justify-between gap-3 px-3 text-body">
      <span className="truncate text-foreground">Event {i + 1}</span>
      <span className="tabular-nums text-muted-foreground">#{(i * 7919) % 100000}</span>
    </div>
  )}
/>

# Measured rows in a ScrollArea

Without `itemHeight` each row is measured as it renders, so rows can wrap. Inside a ScrollArea the area scrolls the list, header included.

<ScrollArea className="h-72 w-full max-w-md rounded-xl border border-border">
  <p className="px-3 pt-3 pb-2 text-caption text-muted-foreground">2,000 notes</p>
  <VirtualList
    label="Notes"
    count={2000}
    estimateHeight={48}
    renderItem={i => (
      <div className="flex flex-col gap-1 px-3 py-2 text-body">
        <span className="text-foreground">Note {i + 1}</span>
        {i % 3 === 0 && <span className="text-caption text-muted-foreground">A longer note that wraps onto a second line, so this row is taller than the ones around it.</span>}
      </div>
    )}
  />
</ScrollArea>
