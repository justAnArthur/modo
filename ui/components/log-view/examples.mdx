# Long log

Ten thousand lines with numbers: the lines are a VirtualList, so it scrolls as smoothly as a short one.

<div className="w-full max-w-2xl">
  <LogView
    lineNumbers
    follow={false}
    maxHeight={320}
    lines={Array.from({ length: 10000 }, (_, i) =>
      i % 50 === 0
        ? '\u001b[33mGET\u001b[0m /api/items?page=' + i / 50 + ' \u001b[33m304\u001b[0m'
        : '\u001b[32mGET\u001b[0m /api/items/' + i + ' \u001b[32m200\u001b[0m \u001b[2m' + (i % 17) + 'ms\u001b[0m'
    )}
  />
</div>
