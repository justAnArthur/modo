# Two panes

An app with only changes and tasks passes `panes={['changes', 'tasks']}` and just their data; `badges` counts on the tabs' glyphs, and with no `extensions` there is no +. `paneProps` hands each pane its callbacks: here Tasks gets none, so it only reports.

<div className="flex h-[480px] w-full max-w-sm overflow-hidden rounded-xl border border-border bg-background">
  <SidePane
    data={{ changes: SIDE_PANE_DATA.changes, tasks: SIDE_PANE_DATA.tasks }}
    panes={['changes', 'tasks']}
    badges={{ changes: SIDE_PANE_DATA.changes.length, tasks: SIDE_PANE_DATA.tasks.filter(t => t.status === 'running').length }}
    paneProps={{ changes: { branch: 'feat/safe-redirect', ahead: 2 } }}
    className="flex-1"
  />
</div>
