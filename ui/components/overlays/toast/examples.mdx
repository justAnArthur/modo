import Toast, { toast } from './index'
import Button from '../../button'
import GlobalDemo from './global-demo'

# States

Each state sets the icon and its color. A toast with a description melts from the pill into a body a beat after it lands, and folds back before it leaves; hover keeps it open.

<Toast position="bottom-center">
  <div className="flex flex-wrap items-center justify-center gap-3">
    <Toast.Trigger type="success" title="Saved" description="Your changes are live for everyone on the team." render={<Button variant="secondary">Success</Button>} />
    <Toast.Trigger type="error" title="Upload failed" description="The file is larger than 25 MB." render={<Button variant="secondary">Error</Button>} />
    <Toast.Trigger type="warning" title="Storage almost full" description="You've used 92% of your plan." render={<Button variant="secondary">Warning</Button>} />
    <Toast.Trigger type="info" title="New version" render={<Button variant="secondary">Info</Button>} />
  </div>
</Toast>

# From anywhere

Mount one `Toast` with `manager={toast}` near the root, then call `toast()` from any handler or module, inside React or not. Each call returns a handle to `update` or `dismiss` it: a `loading` toast spins until it is updated to another state, then leaves on the `Toast`'s timeout; titles and descriptions take any node, `icon` swaps the glyph and `action` adds a button.

<Toast manager={toast} position="bottom-center">
  <GlobalDemo />
</Toast>

# Promise

`promise` runs a task: the pill spins while it is pending, then crossfades into the `success` or `error` toast.

<Toast position="bottom-center">
  <Toast.Trigger
    title="Publishing…"
    promise={() => new Promise(resolve => setTimeout(resolve, 1800))}
    success={{ title: 'Published', description: 'The page is live at modo.dev/docs.' }}
    error={{ title: 'Could not publish' }}
    render={<Button variant="secondary">Publish</Button>}
  />
</Toast>

# Action

An `action` puts a button in the body.

<Toast position="bottom-center">
  <Toast.Trigger
    type="action"
    title="Message archived"
    description="It moved to the archive folder."
    action={{ label: 'Undo' }}
    render={<Button variant="secondary">Archive</Button>}
  />
</Toast>

Any node works as the action: `Toast.Action` and `Toast.Close` are the toast's own buttons, so a custom row needs no Base UI import.

<Toast position="bottom-center">
  <Toast.Trigger
    type="action"
    title="Invite sent"
    description="Ada can join the workspace for the next 7 days."
    action={
      <div className="flex gap-2">
        <Toast.Action>Copy link</Toast.Action>
        <Toast.Close>Dismiss</Toast.Close>
      </div>
    }
    render={<Button variant="secondary">Invite</Button>}
  />
</Toast>

# Positions

`position` puts the stack in a corner or centered on an edge; the pill lands on that side and opens into a card.

<div className="flex flex-wrap items-center justify-center gap-3">
  <Toast position="top-left">
    <Toast.Trigger type="success" title="Top left" description="Slides in from the left edge." render={<Button variant="secondary">Top left</Button>} />
  </Toast>
  <Toast position="top-center">
    <Toast.Trigger type="info" title="Top center" description="Centered on the top edge." render={<Button variant="secondary">Top center</Button>} />
  </Toast>
  <Toast position="bottom-right">
    <Toast.Trigger type="info" title="Bottom right" description="Slides in from the right edge." render={<Button variant="secondary">Bottom right</Button>} />
  </Toast>
</div>
