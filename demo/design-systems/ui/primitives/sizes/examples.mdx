# The principle

The same toolbar line at each step, one SizeProvider per row; the row gap
steps from 8px to 4px.

# Mixed controls

Tabs, Button, Badge and Switch read the step from the provider; none of them
is told its size.

# Typography scale

Each role at both steps (`useTypeScale()`). The default column is also the
`text-<role>` utilities, the compact one `text-<role>-compact`
(tokens/typography.css).

<div className="grid w-full gap-8 sm:grid-cols-2">
  {[['Default', 0], ['Compact', 1]].map(([step, col]) => (
    <div key={step} className="flex min-w-0 flex-col gap-2">
      <span className="text-body font-semibold text-foreground">{step}</span>
      {[
        { role: 'display', px: [28, 24], size: ['text-display', 'text-display-compact'], weight: 'font-bold', sample: 'Fluid Functionalism' },
        { role: 'title', px: [16, 15], size: ['text-title', 'text-title-compact'], weight: 'font-semibold', sample: 'Create teamspace' },

# Component size prop

One Button and one Badge opt back into the default step inside a compact
region.

  <div className="flex flex-wrap items-center gap-2">
    <Button variant="tertiary">Compact · 28px</Button>
    <Button size="default">Default · 36px</Button>
    <Badge>Compact</Badge>
    <Badge size="default">Default</Badge>
  </div>
</SizeProvider>
