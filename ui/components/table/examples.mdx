# Basic

Body rows join the fluid hover highlight in document order, so they need no
`index`; the header row stays out.

  <Table>
    <Table.Header>

        <Table.Head>Name</Table.Head>
        <Table.Head>Role</Table.Head>

    </Table.Header>

# Compact

`size="compact"` lands every row on the 28px step with 12px text, for
dense data.

<div className="w-full">
  <Table size="compact">
    <Table.Header>
      <Table.Row>
        <Table.Head>Name</Table.Head>
        <Table.Head>Role</Table.Head>
        <Table.Head>Status</Table.Head>
      </Table.Row>
    </Table.Header>
    <Table.Body>
      {[['Alice', 'Engineer', 'Active'], ['Bob', 'Designer', 'Away'], ['Carol', 'Manager', 'Active'], ['Dan', 'Researcher', 'Offline']].map((row, i) => (
        <Table.Row key={row[0]} index={i}>
          {row.map((cell) => (
            <Table.Cell key={cell}>{cell}</Table.Cell>
          ))}
        </Table.Row>
      ))}
    </Table.Body>
  </Table>
</div>

# Sortable

A head with `sortDirection` and `onSort` becomes a sort button: a press cycles ascending, descending and unsorted, and its arrow crossfades into the new direction. Here a small stage sorts the rows.

# Sort without state

`defaultSortDirection` lets a head keep its own direction, for a table that sorts elsewhere (a server, TanStack) and only listens to `onSort`.

<div className="w-full">
  <Table>
    <Table.Header>
      <Table.Row>
        <Table.Head defaultSortDirection="desc">Invoice</Table.Head>
        <Table.Head defaultSortDirection={false}>Customer</Table.Head>
        <Table.Head>Status</Table.Head>
      </Table.Row>
    </Table.Header>
    <Table.Body>
      <Table.Row index={0}>
        <Table.Cell>INV-003</Table.Cell>

      </Table.Row>
    </Table.Body>
  </Table>
</div>

# Stacked on small screens

`stacked` turns every row into a two-column card below the `md` breakpoint: the header hides and each cell is led by its muted `label` and its value reads in the primary text colour. Narrow the window to see it; `stacked={false}` on a header or row keeps it tabular.

<div className="w-full">
  <Table stacked>
    <Table.Header>
      <Table.Row>
        <Table.Head>Name</Table.Head>
        <Table.Head>Role</Table.Head>
        <Table.Head>Team</Table.Head>
        <Table.Head>Status</Table.Head>
      </Table.Row>
    </Table.Header>
    <Table.Body>
      {[['Alice', 'Engineer', 'Platform', 'Active'], ['Bob', 'Designer', 'Brand', 'Away'], ['Carol', 'Manager', 'Platform', 'Active']].map(row => (
        <Table.Row key={row[0]}>
          <Table.Cell label="Name">{row[0]}</Table.Cell>
          <Table.Cell label="Role">{row[1]}</Table.Cell>
          <Table.Cell label="Team">{row[2]}</Table.Cell>
          <Table.Cell label="Status">{row[3]}</Table.Cell>
        </Table.Row>
      ))}
    </Table.Body>
  </Table>
</div>
