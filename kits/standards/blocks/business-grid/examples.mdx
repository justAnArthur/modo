import BusinessGrid from './index'
import { BUSINESSES, NOW, PACKS, STATUS, WORKERS } from '../../mock/status'

# Camasys

One website against Website v2. Hover a cell for its evidence; a worker is on the security headers, robots.txt passes the older v1 of its item, and the sitemap check is a week old.

<BusinessGrid
  business={BUSINESSES[0]}
  packs={PACKS}
  cells={STATUS.camasys}
  workers={WORKERS}
  now={NOW}
  className="h-[420px]"
/>

# Two kinds of asset

modo stays on Website v1 (no sitemap health or hero yet) and adopts Repo v1: repo items don't apply to the docs site, website items don't apply to the repo. Its security headers are waived.

<BusinessGrid
  business={BUSINESSES.find(b => b.id === 'modo')}
  packs={PACKS}
  cells={STATUS.modo}
  workers={WORKERS}
  now={NOW}
  className="h-[460px]"
/>

# Picking failing cells

⌘-click failing cells on one asset, or tick its box: Fix N with ▾ worker sends them as one run.

<BusinessGrid
  business={BUSINESSES.find(b => b.id === 'uteg')}
  packs={PACKS}
  cells={STATUS.uteg}
  workers={WORKERS}
  defaultSelected={['site:website/og-image', 'site:website/og-video', 'site:website/structured-data']}
  now={NOW}
  className="h-[420px]"
/>

# A check under way

Every cell but the waived one is being checked: each spins and keeps its last result for its card, the coverage holds still, and nothing can be picked until the results land.

<BusinessGrid
  business={BUSINESSES.find(b => b.id === 'modo')}
  packs={PACKS}
  cells={STATUS.modo.map(cell => (cell.state === 'waived' ? cell : { ...cell, checking: true }))}
  workers={WORKERS}
  now={NOW}
  className="h-[460px]"
/>

# Fix not available yet

`fixDisabled` keeps the picking but dims Fix N with ▾ worker; `fixDisabledReason` says why in a tooltip over it.

<BusinessGrid
  business={BUSINESSES.find(b => b.id === 'uteg')}
  packs={PACKS}
  cells={STATUS.uteg}
  workers={WORKERS}
  defaultSelected={['site:website/og-image', 'site:website/og-video', 'site:website/structured-data']}
  fixDisabled
  fixDisabledReason="Fix runs come in the next version."
  now={NOW}
  className="h-[420px]"
/>

# Opening an item or a pack

With `onOpenItem` and `onOpenPack` the column heads and the pack's head are buttons: hover one, press it to open the item or the pack in the side pane. `activeItem` lights the open item's head and column, `activePack` the pack's head.

<BusinessGrid
  business={BUSINESSES[0]}
  packs={PACKS}
  cells={STATUS.camasys}
  workers={WORKERS}
  onOpenItem={() => {}}
  onOpenPack={() => {}}
  activeItem="website/og-video"
  now={NOW}
  className="h-[420px]"
/>
