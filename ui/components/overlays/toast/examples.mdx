import Toast, { toast } from './index'
import Button from '../../button'

# States

Each state sets the icon and its color. A toast with a description melts from the pill into a body a beat after it lands, and folds back before it leaves; hover keeps it open.

<Toast position="bottom-right">
  <div className="flex flex-wrap items-center justify-center gap-3">
    <Toast.Trigger type="success" title="Saved" description="Your changes are live for everyone on the team." render={<Button variant="secondary">Success</Button>} />
    <Toast.Trigger type="error" title="Upload failed" description="The file is larger than 25 MB." render={<Button variant="secondary">Error</Button>} />
    <Toast.Trigger type="warning" title="Storage almost full" description="You've used 92% of your plan." render={<Button variant="secondary">Warning</Button>} />
    <Toast.Trigger type="info" title="New version" render={<Button variant="secondary">Info</Button>} />
  </div>
</Toast>

# Promise

`promise` runs a task: the pill spins while it is pending, then crossfades into the `success` or `error` toast.

<Toast position="bottom-left">
  <Toast.Trigger
    title="Publishing…"
    promise={() => new Promise(resolve => setTimeout(resolve, 1800))}
    success={{ title: 'Published', description: 'The page is live at modo.dev/docs.' }}
    error={{ title: 'Could not publish' }}
    render={<Button variant="secondary">Publish</Button>}
  />
</Toast>

# Action

An `action` puts a button in the body.

<Toast position="top-right">
  <Toast.Trigger
    type="action"
    title="Message archived"
    description="It moved to the archive folder."
    action={{ label: 'Undo' }}
    render={<Button variant="secondary">Archive</Button>}
  />
</Toast>

# From anywhere

Mount one `<Toast manager={toast} />` and call the global `toast` from any handler or module, React or not. It takes options or just a title and returns the toast's id; `toast.loading` stays until `toast.update` turns it into a result, which then leaves on the default timeout. `useToast()` under that `Toast` works on the same stack.

<Toast manager={toast} position="bottom-right">
  <div className="flex flex-wrap items-center justify-center gap-3">
    <Button variant="secondary" onClick={() => toast.success({ title: 'Saved', description: 'Called from a plain handler.' })}>Success</Button>
    <Button
      variant="secondary"
      onClick={() => {
        const id = toast.loading('Syncing…')
        setTimeout(() => toast.update(id, { type: 'success', title: 'Synced' }), 1600)
      }}
    >
      Loading, then update
    </Button>
    <Button
      variant="secondary"
      onClick={() =>
        toast
          .promise(new Promise((resolve, reject) => setTimeout(Math.random() < 0.5 ? resolve : () => reject(new Error('Network error')), 1600)), {
            loading: 'Publishing…',
            success: 'Published',
            error: error => ({ title: 'Could not publish', description: error.message }),
          })
          .catch(() => {})
      }
    >
      Promise
    </Button>
    <Button variant="ghost" onClick={() => toast.close()}>Close all</Button>
  </div>
</Toast>

# Positions

`position` puts the stack in a corner or centered on an edge; the pill sits on that side and the body opens away from the edge.

<div className="flex flex-wrap items-center justify-center gap-3">
  <Toast position="top-left">
    <Toast.Trigger type="success" title="Top left" description="The body opens downward." render={<Button variant="secondary">Top left</Button>} />
  </Toast>
  <Toast position="top-center">
    <Toast.Trigger type="info" title="Top center" description="Centered on the top edge." render={<Button variant="secondary">Top center</Button>} />
  </Toast>
  <Toast position="bottom-center">
    <Toast.Trigger type="info" title="Bottom center" description="The body opens upward." render={<Button variant="secondary">Bottom center</Button>} />
  </Toast>
</div>
