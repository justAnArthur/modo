import Textarea from './index'
import Button from '../../button'
import Input, { InputGroup, Label } from '../input'

# Basic

Type past the third line: the box grows with the text, then scrolls at eight rows.

<div className="w-72 max-w-full">
  <Textarea placeholder="Write a note..." />
</div>

# Variants

`borderless` is invisible until hovered or focused; `bordered` is framed at rest.

<div className="flex flex-col gap-3 w-72 max-w-full">
  <Textarea minRows={2} placeholder="Borderless" />
  <Textarea variant="bordered" minRows={2} placeholder="Bordered" />
</div>

# With a Label

`Label` pairs with the textarea through `htmlFor` and `id`.

<div className="flex flex-col gap-1 w-72 max-w-full">
  <Label htmlFor="textarea-bio">Bio</Label>
  <Textarea id="textarea-bio" placeholder="A few words about you" />
</div>

# Rows

`minRows` sets the empty height and `maxRows` where growth stops. Equal values give a fixed box.

<div className="flex flex-col gap-3 w-72 max-w-full">
  <Textarea minRows={1} maxRows={4} placeholder="Starts at one row, grows to four" />
  <Textarea minRows={4} maxRows={4} placeholder="Fixed at four rows" />
</div>

# In a form

One row lines up with an Input of the same size, so the two stack without a seam.

<div className="flex flex-col gap-3 w-72 max-w-full">
  <div className="flex flex-col gap-1">
    <Label htmlFor="textarea-form-title">Title</Label>
    <Input id="textarea-form-title" placeholder="Short summary" />
  </div>
  <div className="flex flex-col gap-1">
    <Label htmlFor="textarea-form-body">Description</Label>
    <Textarea id="textarea-form-body" minRows={1} placeholder="Add details" />
  </div>
</div>

# In a group

Inside `InputGroup.Field` the textarea joins the group's hover, and the field's `error` turns it destructive.

<InputGroup>
  <InputGroup.Field index={0} label="Name" placeholder="Your name" />
  <InputGroup.Field index={1} label="Feedback" error="Tell us a little more.">
    <Textarea defaultValue="Nice" />
  </InputGroup.Field>
</InputGroup>

# Compact

`size="compact"` steps the text and padding down the size ladder.

<div className="w-72 max-w-full">
  <Textarea size="compact" minRows={2} placeholder="Dense note..." />
</div>

# Invalid

`invalid` turns the field destructive.

<div className="flex flex-col gap-1 w-72 max-w-full">
  <Label htmlFor="textarea-invalid" invalid>
    Message
  </Label>
  <Textarea id="textarea-invalid" defaultValue="Too short" invalid />
</div>

# Uncontrolled

With neither `value` nor `onChange` the DOM holds the text, so `ref` is the real `<textarea>`: `defaultValue`, `ref.current.value = ''` and a native form reset behave as on any textarea. Type, grow the box, then reset: the text goes back to its default and the box re-fits.

<form className="flex flex-col items-start gap-2 w-72 max-w-full">
  <Textarea name="note" aria-label="Note" defaultValue={'First line\nSecond line\nThird line\nFourth line'} />
  <Button type="reset" variant="ghost">Reset</Button>
</form>

```tsx
const ref = useRef<HTMLTextAreaElement>(null)

<Textarea ref={ref} name="note" defaultValue="Hello" />

ref.current.value // what was typed
ref.current.value = '' // clears it
```


Choose one mode per instance. A `defaultValue` with an `onChange` that is passed on some renders and not others would flip the textarea between DOM-held and controlled text.

# With a form library

A `register()`-style form needs the DOM mode, but its `onChange` takes an event where the Textarea's takes a string, so the result can't be spread whole. Only that key clashes: take `onChange` out and pass it as `onInput`, the event handler that fires on every keystroke. `rest` carries `name`, `ref` and `onBlur` straight through.

```tsx
const { onChange, ...rest } = register('note')

<Textarea {...rest} onInput={onChange} />
```
