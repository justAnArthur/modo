# Basic

The inline panel, running its own selection: `defaultCheckedIndex` makes
the rows radio options and the panel moves the marker itself.

<Dropdown defaultCheckedIndex={0}>
  <Dropdown.Item index={0} icon={SquareLibrary} label="Teamspaces" />
  <Dropdown.Item index={1} icon={Clock} label="Recents" />
  <Dropdown.Item index={2} icon={Star} label="Favorites" />
  <Dropdown.Item index={3} icon={Users} label="Shared" />
  <Dropdown.Item index={4} icon={Lock} label="Private" />
</Dropdown>

# Groups

Without any checked state the rows are plain actions. Dropdown.Label
captions a run of them, Dropdown.Separator rules between the runs, and the
indices keep counting across both.

<Dropdown>
  <Dropdown.Label>Account</Dropdown.Label>
  <Dropdown.Item index={0} icon={Mail} label="Email" />
  <Dropdown.Item index={1} icon={Bell} label="Notifications" />
  <Dropdown.Item index={2} icon={Shield} label="Privacy" />
  <Dropdown.Separator />
  <Dropdown.Label>Appearance</Dropdown.Label>
  <Dropdown.Item index={3} icon={Settings} label="General" />
  <Dropdown.Item index={4} icon={Palette} label="Theme" />
  <Dropdown.Item index={5} icon={Monitor} label="Display" />
</Dropdown>

# Triggered menu

3 parts: Dropdown.Menu, Dropdown.Trigger, Dropdown.Content. Any element
goes in `render`, and picking a row closes the menu.

<Dropdown.Menu>
  <Dropdown.Trigger render={<Button variant="ghost">Open menu</Button>} />
  <Dropdown.Content defaultCheckedIndex={0}>
    <Dropdown.Item index={0} icon={SquareLibrary} label="Teamspaces" />
    <Dropdown.Item index={1} icon={Clock} label="Recents" />
    <Dropdown.Item index={2} icon={Star} label="Favorites" />
    <Dropdown.Item index={3} icon={Users} label="Shared" />
    <Dropdown.Item index={4} icon={Lock} label="Private" />
  </Dropdown.Content>
</Dropdown.Menu>

# Morph

The menu oozes out of its trigger by default. `effect="morph"` with `hideSource` turns the trigger itself into the menu and shrinks it back, one continuous surface.

<div className="flex flex-wrap items-start justify-center gap-3">
  <Dropdown.Menu>
    <Dropdown.Trigger render={<Button variant="secondary">Goo</Button>} />
    <Dropdown.Content defaultCheckedIndex={0}>
      <Dropdown.Item index={0} icon={Mail} label="Email" />
      <Dropdown.Item index={1} icon={Bell} label="Notifications" />
      <Dropdown.Item index={2} icon={Shield} label="Privacy" />
    </Dropdown.Content>
  </Dropdown.Menu>
  <Dropdown.Menu>
    <Dropdown.Trigger render={<Button variant="secondary">Morph</Button>} />
    <Dropdown.Content effect="morph" hideSource defaultCheckedIndex={0}>
      <Dropdown.Item index={0} icon={Settings} label="General" />
      <Dropdown.Item index={1} icon={Palette} label="Theme" />
      <Dropdown.Item index={2} icon={Monitor} label="Display" />
    </Dropdown.Content>
  </Dropdown.Menu>
</div>

# Multiple selection

`defaultCheckedIndices` (or `checkedIndices`): rows become checkboxes, the
menu stays open as you toggle, and touching picks share one background.

<Dropdown.Menu>
  <Dropdown.Trigger render={<Button variant="ghost">Status</Button>} />
  <Dropdown.Content defaultCheckedIndices={[0, 1, 2]}>
    {['Open', 'In progress', 'In review', 'Blocked', 'Done', 'Archived'].map((status, i) => (
      <Dropdown.Item key={status} index={i} label={status} />
    ))}
  </Dropdown.Content>
</Dropdown.Menu>

# Searchable menu

Put a Dropdown.Search marked `filter` first and the panel filters its own
rows by `label`. Type to filter, press Enter to pick the first match.

<Dropdown.Menu>
  <Dropdown.Trigger render={<Button variant="ghost" trailingIcon={ChevronDown}>Language</Button>} />
  <Dropdown.Content defaultCheckedIndex={0}>
    <Dropdown.Search filter placeholder="Search languages" />
    {['Auto detect', 'Arabic', 'Bengali', 'Chinese (Simplified)', 'Czech', 'Danish', 'Dutch', 'English (UK)', 'English (US)', 'Finnish', 'French', 'German', 'Greek', 'Hebrew', 'Hindi', 'Hungarian', 'Indonesian', 'Italian', 'Japanese', 'Korean', 'Norwegian', 'Polish', 'Portuguese (Brazil)', 'Romanian', 'Russian', 'Spanish', 'Swedish', 'Thai', 'Turkish', 'Ukrainian', 'Vietnamese'].map((language, i) => (
      <Dropdown.Item key={language} index={i} label={language} />
    ))}
    <Dropdown.Empty>No languages found</Dropdown.Empty>
  </Dropdown.Content>
</Dropdown.Menu>

# Searchable multiple selection

Both at once. The panel filters the rows and keeps the picks on the rows
themselves, so a filtered-away pick is still checked when it comes back.

<Dropdown.Menu>
  <Dropdown.Trigger render={<Button variant="ghost">Labels</Button>} />
  <Dropdown.Content defaultCheckedIndices={[0, 3]}>
    <Dropdown.Search filter placeholder="Search labels" />
    {['Bug', 'Feature', 'Docs', 'Design', 'Performance', 'Accessibility', 'Refactor', 'Testing', 'Infrastructure', 'Security', 'Good first issue', 'Help wanted'].map((label, i) => (
      <Dropdown.Item key={label} index={i} label={label} />
    ))}
    <Dropdown.Empty>No labels found</Dropdown.Empty>
  </Dropdown.Content>
</Dropdown.Menu>

# Children items

Rows written shadcn-style: the content as children and no `index` — each row
takes its place in document order, conditional rows included. `shortcut`
adds a muted caption at the end, `inset` lines a text-only row up with the
rows that have an icon, and `onSelect` runs on a pick by pointer or keyboard.

<Dropdown.Menu>
  <Dropdown.Trigger asChild>
    <Button variant="ghost" size="icon" aria-label="Row actions"><Ellipsis /></Button>
  </Dropdown.Trigger>
  <Dropdown.Content align="end">
    <Dropdown.Item icon={Pencil} shortcut="⌘E">Edit</Dropdown.Item>
    <Dropdown.Item icon={Copy} shortcut="⌘D">Duplicate</Dropdown.Item>
    <Dropdown.Item inset>Move to…</Dropdown.Item>
    <Dropdown.Item disabled inset>Archive</Dropdown.Item>
    <Dropdown.Separator />
    <Dropdown.Item icon={Trash2} shortcut="⌫">Delete</Dropdown.Item>
  </Dropdown.Content>
</Dropdown.Menu>

# Groups and labels

`Dropdown.Group` holds a run of related rows; a `Dropdown.Label` inside it
names the group for assistive tech. Labels and separators break the row
order, so nothing selected melts across them.

<Dropdown.Menu>
  <Dropdown.Trigger render={<Button variant="secondary" leadingIcon={User}>Account</Button>} />
  <Dropdown.Content>
    <Dropdown.Group>
      <Dropdown.Label>My account</Dropdown.Label>
      <Dropdown.Item icon={User}>Profile</Dropdown.Item>
      <Dropdown.Item icon={Settings}>Settings</Dropdown.Item>
    </Dropdown.Group>
    <Dropdown.Separator />
    <Dropdown.Group>
      <Dropdown.Label inset>Team</Dropdown.Label>
      <Dropdown.Item inset>Invite members</Dropdown.Item>
      <Dropdown.Item inset>New team</Dropdown.Item>
    </Dropdown.Group>
    <Dropdown.Separator />
    <Dropdown.Item icon={LogOut}>Log out</Dropdown.Item>
  </Dropdown.Content>
</Dropdown.Menu>

# Shortcut

`Dropdown.Shortcut` is the trailing caption on its own, for rows that lay
out their own content.

<Dropdown className="w-64">
  <Dropdown.Item>
    <Mail />
    New message
    <Dropdown.Shortcut>⌘N</Dropdown.Shortcut>
  </Dropdown.Item>
  <Dropdown.Item>
    <Bell />
    Mute thread
    <Dropdown.Shortcut>⇧⌘M</Dropdown.Shortcut>
  </Dropdown.Item>
</Dropdown>

# Submenu

A `Dropdown.Sub` holds a trigger row and its panel. ArrowRight, a press or a
resting pointer opens it, ArrowLeft or Escape closes it; it grows out of its
row, which stays lit while it is open, and nests as deep as you like.

<Dropdown.Menu>
  <Dropdown.Trigger render={<Button variant="secondary">Options</Button>} />
  <Dropdown.Content keepMounted>
    <Dropdown.Item icon={User}>Profile</Dropdown.Item>
    <Dropdown.Sub>
      <Dropdown.SubTrigger icon={Palette}>Theme</Dropdown.SubTrigger>
      <Dropdown.SubContent keepMounted>
        <Dropdown.RadioGroup defaultValue="system">
          <Dropdown.RadioItem value="light">Light</Dropdown.RadioItem>
          <Dropdown.RadioItem value="dark">Dark</Dropdown.RadioItem>
          <Dropdown.RadioItem value="system">System</Dropdown.RadioItem>
        </Dropdown.RadioGroup>
      </Dropdown.SubContent>
    </Dropdown.Sub>
    <Dropdown.Sub>
      <Dropdown.SubTrigger icon={Users}>Invite users</Dropdown.SubTrigger>
      <Dropdown.SubContent>
        <Dropdown.Item icon={Mail}>Email</Dropdown.Item>
        <Dropdown.Item icon={Copy}>Copy link</Dropdown.Item>
        <Dropdown.Separator />
        <Dropdown.Sub>
          <Dropdown.SubTrigger inset>More</Dropdown.SubTrigger>
          <Dropdown.SubContent>
            <Dropdown.Item>Slack</Dropdown.Item>
            <Dropdown.Item>Teams</Dropdown.Item>
          </Dropdown.SubContent>
        </Dropdown.Sub>
      </Dropdown.SubContent>
    </Dropdown.Sub>
    <Dropdown.Separator />
    <Dropdown.Item icon={LogOut}>Log out</Dropdown.Item>
  </Dropdown.Content>
</Dropdown.Menu>

# Checkbox items

`Dropdown.CheckboxItem` toggles itself — `defaultChecked`, or `checked` with
`onCheckedChange` — and keeps the menu open. Touching checked rows share one
background, as in a multiple selection. Uncontrolled rows live inside the
popup, so `keepMounted` keeps their state across opens.

<Dropdown.Menu>
  <Dropdown.Trigger render={<Button variant="secondary" trailingIcon={ChevronDown}>Columns</Button>} />
  <Dropdown.Content align="end" keepMounted>
    <Dropdown.Label>Visible columns</Dropdown.Label>
    <Dropdown.CheckboxItem defaultChecked>Name</Dropdown.CheckboxItem>
    <Dropdown.CheckboxItem defaultChecked>Email</Dropdown.CheckboxItem>
    <Dropdown.CheckboxItem>Role</Dropdown.CheckboxItem>
    <Dropdown.CheckboxItem defaultChecked>Status</Dropdown.CheckboxItem>
    <Dropdown.CheckboxItem disabled>Created</Dropdown.CheckboxItem>
  </Dropdown.Content>
</Dropdown.Menu>

# Radio group

`Dropdown.RadioGroup` picks one of its `Dropdown.RadioItem` rows by `value`
(`defaultValue`, or `value` with `onValueChange`). Picking one closes the
menu.

<Dropdown.Menu>
  <Dropdown.Trigger render={<Button variant="secondary" trailingIcon={ChevronDown}>Language</Button>} />
  <Dropdown.Content keepMounted>
    <Dropdown.RadioGroup defaultValue="sk">
      <Dropdown.Label>Language</Dropdown.Label>
      <Dropdown.RadioItem value="sk">Slovenčina</Dropdown.RadioItem>
      <Dropdown.RadioItem value="cs">Čeština</Dropdown.RadioItem>
      <Dropdown.RadioItem value="en">English</Dropdown.RadioItem>
      <Dropdown.RadioItem value="de" disabled>Deutsch</Dropdown.RadioItem>
    </Dropdown.RadioGroup>
  </Dropdown.Content>
</Dropdown.Menu>

# Inside a dialog

A menu lifts 2 surface levels above whatever it opens over — a dialog
included — and so does its submenu above the menu.

<Dialog>
  <Dialog.Trigger render={<Button variant="tertiary">Open dialog</Button>} />
  <Dialog.Content>
    <Dialog.Header>
      <Dialog.Title>Share document</Dialog.Title>
      <Dialog.Description>Pick who can see it.</Dialog.Description>
    </Dialog.Header>
    <Dropdown.Menu>
      <Dropdown.Trigger render={<Button variant="secondary" trailingIcon={ChevronDown}>Access</Button>} />
      <Dropdown.Content keepMounted>
        <Dropdown.RadioGroup defaultValue="team">
          <Dropdown.RadioItem value="private" icon={Lock}>Only me</Dropdown.RadioItem>
          <Dropdown.RadioItem value="team" icon={Users}>My team</Dropdown.RadioItem>
        </Dropdown.RadioGroup>
        <Dropdown.Separator />
        <Dropdown.Sub>
          <Dropdown.SubTrigger icon={Shield}>Advanced</Dropdown.SubTrigger>
          <Dropdown.SubContent keepMounted>
            <Dropdown.CheckboxItem defaultChecked>Allow comments</Dropdown.CheckboxItem>
            <Dropdown.CheckboxItem>Allow downloads</Dropdown.CheckboxItem>
          </Dropdown.SubContent>
        </Dropdown.Sub>
      </Dropdown.Content>
    </Dropdown.Menu>
  </Dialog.Content>
</Dialog>
