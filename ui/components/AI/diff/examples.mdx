# File change

A patch with its path: the header counts the change, added lines take the success hue, removed lines the error hue.

<div className="w-full max-w-2xl">
  <Diff
    path="ui/components/meter/index.tsx"
    patch={`@@ -12,7 +12,8 @@ import { cn } from '../../lib/utils'
 const BAR_FILL: Record<MeterTone, string> = {
-  default: 'bg-foreground',
+  default: 'bg-muted-foreground',
   warning: 'bg-status-warning',
   error: 'bg-status-error',
+  // the track is bg-active, so it reads on any surface
 }`}
  />
</div>
