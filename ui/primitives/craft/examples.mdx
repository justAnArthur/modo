# Weight without reflow

Click through the tabs on each side and watch the labels next to the one you picked.

<Craft
  bad={<BoldTabs labels={['Overview', 'Activity', 'Settings']} />}
  badNote="The selected label gets wider, so every tab after it shifts."
  good={
    <TabsSubtle defaultSelectedIndex={0}>
      {['Overview', 'Activity', 'Settings'].map((label, i) => (
        <TabsSubtle.Item key={label} index={i} label={label} />
      ))}
    </TabsSubtle>
  }
  goodNote="An invisible semibold copy holds the width, and the weight is paired with an optical size. Nothing moves."
/>

# Hover that never blinks

<Craft
  bad={<RowHover items={['Profile', 'Billing', 'Team', 'Notifications']} />}
