The picture fades in once it has loaded. Without one, or when it fails, initials (or a person glyph) show on a neutral ground.

# Square

`shape="square"` is for teams, organizations and things. It takes the shape's item radius, so pill mode rounds it further.

<div className="flex items-center gap-3">
  <Avatar shape="square">
    <Avatar.Fallback>AC</Avatar.Fallback>
  </Avatar>
  <Avatar shape="square">
    <Avatar.Fallback>
      <Building2 size={16} strokeWidth={1.5} aria-hidden />
    </Avatar.Fallback>
  </Avatar>
</div>

# Sizes

One control tall: 36px, and 28px in a compact region or with `size="compact"`. A size off the ladder goes through `className`.

<div className="flex flex-col gap-3">
  <div className="flex items-center gap-3">
    <Avatar>
      <Avatar.Fallback>AL</Avatar.Fallback>
    </Avatar>
    <Avatar size="compact">
      <Avatar.Fallback>AL</Avatar.Fallback>
    </Avatar>
    <Avatar size="compact" className="size-5 text-micro">
      <Avatar.Fallback>A</Avatar.Fallback>
    </Avatar>
