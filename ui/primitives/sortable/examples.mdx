# Tabs

A horizontal list drags by the whole item; Left and Right move a lifted tab.

<Sortable
  label="Open files"

  className="gap-1"

# Inside a list of your own

`as="none"` renders no list and no item roles, so the rows of a host list (here a plain `ul`, or a `Sidebar.Menu`) are the ones that move. Name the host list; `useSortableHandle()` wires a button of your own as the handle.

<ul aria-label="Bookmarks" className="flex w-full max-w-xs flex-col">
  <Sortable
    as="none"
    handle
    className="gap-1"
    items={['Release checklist', 'Design review notes', 'On-call runbook'].map(title => ({
      id: title,
      label: title,
      content: <li className="flex h-9 items-center gap-2 px-2 text-body text-foreground"><Sortable.Handle /><span className="min-w-0 flex-1 truncate">{title}</span></li>,
    }))}
  />
</ul>
