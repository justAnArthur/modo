# Searching

`defaultQuery` (or `query`) narrows the list; the hero follows the first match.

<WidgetIsland tab="clipboard">
  <ClipboardHistory clips={CLIPS} defaultQuery="main" now={CLIP_NOW} />

# Paused, an app ignored

`paused` stops recording, with a chip and Resume on the context line; `ignoredApp` says whose copies are never kept.

<WidgetIsland tab="clipboard">
  <ClipboardHistory clips={CLIPS} defaultPaused ignoredApp="1Password" now={CLIP_NOW} />
</WidgetIsland>
