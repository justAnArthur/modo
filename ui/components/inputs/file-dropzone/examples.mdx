# Dropzone

Drag files over the zone, or click it (or Tab to it and press Enter) to pick them. While files are in the air the line says whether all, some or none of them will be taken; files that pass go to the list, the rest to the field's error, and the reasons are announced.

<UploadDemo multiple accept=".pdf,image/*" maxSize={5000000} description="PDF or images, up to 5 MB each, three at most" />

# Single file

Without `multiple` the zone takes one file: drag several and it says the rest will be skipped; drag only files of another type and it refuses the drop.

<Field className="w-96 max-w-full">
  <Field.Label>Avatar</Field.Label>
  <FileDropzone accept="image/*" description="PNG or JPG" />
  <Field.Description>Shown next to your name.</Field.Description>
</Field>

# Compact

The compact step tightens the padding and steps the text down.

<div className="w-80 max-w-full">
  <FileDropzone size="compact" label="Drop a CSV or click to browse" accept=".csv" />
</div>

# Translated

Every line is a prop, the announced reasons included.

<div className="w-96 max-w-full">
  <FileDropzone
    multiple
    label="Presuňte súbory sem alebo kliknite"
    activeLabel="Pustite a pridajte"
    partialLabel="Niektoré súbory sa vynechajú"
    rejectLabel="Tieto súbory nemožno pridať"
    rejectionMessage={({ file }) => `${file.name}: nepodporovaný súbor`}
    description="PDF, najviac 10 MB"
    accept=".pdf"
  />
</div>

# States

Inside a Field the zone takes its state: invalid turns it destructive, required marks the label (and is announced), disabled dims it, read-only takes no files.

<div className="flex flex-col gap-3 w-96 max-w-full">
  <Field invalid required>
    <Field.Label>Contract</Field.Label>
    <FileDropzone accept=".pdf" />
    <Field.Error>Attach the signed contract.</Field.Error>
  </Field>
  <Field disabled>
    <Field.Label>Receipts</Field.Label>
    <FileDropzone label="Uploads are paused" />
  </Field>
  <Field readOnly>
    <Field.Label>Signature</Field.Label>
    <FileDropzone label="No file attached" />
  </Field>
</div>

# File rows

A row shows one file: its glyph or thumbnail, the name, the size or a status line, and a remove button. `status` sets the glyph, and `progress` fills the bar while uploading.

<div className="flex flex-col w-96 max-w-full">
  <FileDropzone.Row name="Quarterly report.pdf" fileSize={2480000} type="application/pdf" status="done" onRemove={() => {}} />
  <FileDropzone.Row name="Site photo.jpg" fileSize={5320000} type="image/jpeg" status="uploading" progress={64} onRemove={() => {}} />
  <FileDropzone.Row name="Budget.xlsx" fileSize={84000} error="Upload failed. Try again." onRemove={() => {}} />
  <FileDropzone.Row name="Contract draft.docx" fileSize={1200000} description="Uploaded yesterday" />
</div>
