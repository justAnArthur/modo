# Hover

With `openOnHover` the trigger opens it on hover too; a tap still toggles it on touch.

<Popover>
  <Popover.Trigger openOnHover delay={100} closeDelay={120} render={<Button variant="tertiary">Hover me</Button>} />
  <Popover.Content>
    <Popover.Title>Liquid preview</Popover.Title>
    <Popover.Description>Move away and it melts back into the button.</Popover.Description>
  </Popover.Content>
</Popover>

# Dismissal

`onOpenChange` gets Base UI's change details with the open state: `details.reason` says what asked (`'escape-key'`, `'outside-press'`, `'trigger-press'`, `'close-press'`, …) and `details.cancel()` keeps the popover as it is. This one ignores a press outside; Escape or Done close it.

<Popover
  onOpenChange={(open, details) => {
    if (!open && details.reason === 'outside-press') details.cancel()
  }}
>
  <Popover.Trigger render={<Button variant="secondary">Pin a note</Button>} />
  <Popover.Content className="w-72 gap-3">
    <Popover.Title>Pinned note</Popover.Title>
    <Popover.Description>Click around the page: it stays until you close it.</Popover.Description>
    <div className="flex justify-end">
      <Popover.Close render={<Button size="compact">Done</Button>} />
    </div>
  </Popover.Content>
</Popover>

# Anchored to a field

`anchor` positions the panel against another element than its trigger, here
the whole field around the icon, and the panel grows out of that box.
`--anchor-width` sizes it to the field. `initialFocus` moves focus to the
first result when it opens from the keyboard and leaves the caret in the field
on a click; `finalFocus` hands focus back to the text, so typing goes on.
`AnchoredDemo` is a docs stage that holds the refs and the picked value:

```tsx
const field = useRef(null)
const input = useRef(null)
const first = useRef(null)

<div ref={field}>
  <Popover>
    <Input ref={input} endAdornment={<Popover.Trigger render={<InputAction label="Recent searches" icon={History} />} />} />
    <Popover.Content
      anchor={field}
      align="start"
      initialFocus={type => (type === 'keyboard' ? first.current : false)}
      finalFocus={input}
      className="w-[var(--anchor-width)] max-w-none"
    >
      …
    </Popover.Content>
  </Popover>
</div>
```
