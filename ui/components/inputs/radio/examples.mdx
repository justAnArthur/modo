import Radio from './index'

# Basic

One option at a time; the selected background follows the pick.

<Radio.Group defaultSelectedIndex={0}>
  {['Option A', 'Option B', 'Option C'].map(label => (
    <Radio key={label} label={label} />
  ))}
</Radio.Group>

# Compact

`size="compact"` pins every row to the 28px step of the size ladder.

<Radio.Group size="compact" defaultSelectedIndex={1}>
  {['Option A', 'Option B', 'Option C'].map(label => (
    <Radio key={label} label={label} />
  ))}
</Radio.Group>

# By value

Give rows a `value` and select by it; the group then renders Base UI radios
for form integration.

<Radio.Group defaultValue="weekly">
  <Radio value="daily" label="Daily digest" />
  <Radio value="weekly" label="Weekly summary" />
  <Radio value="never" label="Never" />
</Radio.Group>

# By value, reported only

With `onValueChange` and no `defaultValue`, the group starts empty and reports each pick; `name` submits the pick in a form.

<Radio.Group name="plan" onValueChange={value => console.log(value)}>
  <Radio value="free" label="Free" />
  <Radio value="pro" label="Pro" />
  <Radio value="team" label="Team" disabled />
</Radio.Group>

# Rich labels

`label` takes any node, here a name and a price; the row is then named by
its content (`aria-labelledby`).

<Radio.Group defaultValue="pro">
  <Radio value="free" label={<span className="flex gap-2">Free <span className="text-muted-foreground">$0</span></span>} />
  <Radio value="pro" label={<span className="flex gap-2">Pro <span className="text-muted-foreground">$12 / month</span></span>} />
</Radio.Group>

# Bare

A `Radio` without a `label` is just the circle, picked by its `value`. Lay bare radios out however you like: when none of the group's direct children is a labelled row, the group draws no rows of its own, and Base UI moves focus and selection with the arrow keys. Name each one with a `<label htmlFor>` pointing at its `id`, or `aria-label`.

<Radio.Group defaultValue="standard" name="shipping" className="w-72 max-w-full">
  {[
    ['standard', 'Standard', '4–6 business days'],
    ['express', 'Express', '1–2 business days'],
    ['pickup', 'Pickup', 'Ready tomorrow'],
  ].map(([value, title, note]) => (
    <div key={value} className="flex items-start gap-2.5">
      <Radio id={`ship-${value}`} value={value} className="mt-0.5" />
      <label htmlFor={`ship-${value}`} className="flex flex-col gap-1 cursor-pointer">
        <span className="text-body text-foreground text-trim">{title}</span>
        <span className="text-caption text-muted-foreground">{note}</span>
      </label>
    </div>
  ))}
</Radio.Group>
