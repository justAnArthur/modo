# Folded work

Press the row: the reasoning and the calls are inside.

<div className="w-full max-w-2xl">
  <WorkSummary summary="Worked for 52s" detail="Thought 8s · 2 reads">
    <Reasoning duration="8s">
      <p className="m-0">The rules live in DESIGN.md; the craft page shows them as pairs.</p>
    </Reasoning>
    <ToolCall.Group>
      <ToolCall index={0} value="design" tool="Read" summary="ui/DESIGN.md" meta="543 lines" />

    </ToolCall.Group>
  </WorkSummary>
</div>

# Running

While the turn runs, the Spinner turns in the row.

<div className="w-full max-w-2xl">
  <WorkSummary summary="Working…" detail="bun run check" running>
    <ToolCall.Group>
      <ToolCall index={0} value="check" tool="Bash" summary="bun run check" status="running" />
    </ToolCall.Group>
  </WorkSummary>
</div>

# Show all

A provider set `open` unfolds every turn's work at once.
