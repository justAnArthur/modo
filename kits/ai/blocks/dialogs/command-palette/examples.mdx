import CommandPalette from './index'
import { ARCHIVED, COMMANDS, GROUPS, PINNED, PROFILES, PROJECTS } from '../../../mock/mock'

# Palette

Press the trigger or ⌘K: the panel grows out of it. Try "canvas" for a session, "work" for a new session under that profile, "review" for a command or "hooks" for a settings section.

<div className="flex h-[520px] w-full items-start justify-center pt-6">
  <CommandPalette
    sessions={[...PINNED, ...GROUPS.flatMap(g => g.sessions), ...ARCHIVED]}
    projects={PROJECTS}
    profiles={PROFILES}
    commands={COMMANDS}
    settings={SETTINGS_SECTIONS}
  />
</div>

# Another profile

With `work` active, new sessions start under it and its own row is disabled. Without `settings`, one row opens the settings window. ⌘K stays with the first palette here.

<div className="flex h-[520px] w-full items-start justify-center pt-6">
  <CommandPalette
    hotkey={false}
    profile="work"
    label="Search work"
    sessions={PINNED}
    projects={PROJECTS}
    profiles={PROFILES}
    commands={COMMANDS}
  />
</div>

# Fewer groups

An app without side panes or a settings window leaves those groups out: `panes={false}` drops Panes and `settings={[]}` drops Settings. `panes={['changes', 'terminal']}` would offer just those two.

<div className="flex h-[520px] w-full items-start justify-center pt-6">
  <CommandPalette
    hotkey={false}
    label="Search lean"
    sessions={PINNED}
    projects={PROJECTS}
    profiles={PROFILES}
    commands={COMMANDS}
    panes={false}
    settings={[]}
  />
</div>

# Hundreds of sessions

Before you type, a group lists its first `recentLimit` rows and counts the rest; type and it searches them all, listing the first `matchLimit` matches. Here 400 sessions, 5 shown until you type "session 1". `searchTranscripts={false}` and `manageProfiles={false}` drop those rows.

<div className="flex h-[520px] w-full items-start justify-center pt-6">
  <CommandPalette
    hotkey={false}
    label="Search many"
    sessions={Array.from({ length: 400 }, (_, i) => ({ ...PINNED[i % PINNED.length], id: `many-${i}`, title: `Session ${i}` }))}
    projects={PROJECTS}
    profiles={PROFILES}
    commands={COMMANDS}
    recentLimit={5}
    matchLimit={10}
    searchTranscripts={false}
    manageProfiles={false}
  />
</div>
