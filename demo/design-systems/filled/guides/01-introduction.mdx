## What's here

- `tokens/` holds the theme, one CSS file per group.
- `primitives/`, `components/`, `blocks/` and `pages/` hold the items, one folder each.
- `guides/` holds free-form pages like this one.

## Writing a guide

Add a `.mdx` file to `guides/`: frontmatter names it, a `01-` prefix orders it, and a folder with an `index.mdx` becomes a landing page with its guides under it.
